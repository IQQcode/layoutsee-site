当前支持 macOS + Android 真机；iOS 与 HarmonyOS 为界面预告。

实时投屏与操控

画面即现场，操作即验证。

  1. 01低延迟投屏，键鼠直接操控真机。
  2. 02多设备同时在线，群控批量执行。
  3. 03常用 adb 操作收敛为界面快捷按钮。

结构化视图感知

控件从「看得到」到「查得清」。

  1. 01视图树与属性面板联动，点哪查哪。
  2. 02XPath 查询与候选选择器，附带命中数。
  3. 03语义摘要低 token 输出，元素带 ref 与归一化边界。

布局智能诊断

让问题有据可查。

  1. 01六类几何与可用性问题检查。
  2. 02返回涉及节点与量化证据，供 Agent 继续分析。
  3. 03语义摘要与诊断联动，先压缩阅读再按需深入。

MCP 接入 AI 工作流

把真机交给 Agent。

  1. 01每台在线设备独立 SSE 端点，按设备暴露能力。
  2. 0212 个内置工具：9 读 3 写，覆盖感知、定位、诊断与操作。
  3. 03只读模式与操作审计，过程可控可回溯。

插件系统

受限但够用的运行时 API。

  1. 01内置日志抓取、快照速览等基础插件。
  2. 02支持扩展工作台界面与 MCP 工具。
  3. 03插件随包分发，开箱即用。

安装三步

从下载到连上第一台设备。

  1. 01 安装 下载 DMG 拖入 Applications；未签名包在「系统设置 → 隐私与安全性」选择「仍要打开」。
  2. 02 准备 adb brew install android-platform-tools，或在设置中指定已有 adb 路径。
  3. 03 连接设备 开启开发者选项与 USB 调试，用支持数据传输的线缆连接，在手机上确认调试授权。
